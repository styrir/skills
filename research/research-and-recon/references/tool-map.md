# Research / Recon Tool Map

## Search / docs / extraction
- `find-docs`: resolve the library ID first, then query the docs ID.
- `duckduckgo-search`: Python `max_results` is keyword-only; use it only as a fallback.
- `perplexity-search`: best for synthesized overviews and citation-backed broad sweeps, not for exact URLs.
- `tavily-cli`: use when you have Tavily available and need search/extract/crawl/research in one place.

## Domain intelligence
- `domain-intel`: passive only; use for subdomains, SSL certs, WHOIS, DNS, and availability.

## Competitive analysis
- `competitive-gap-analysis`: clone references outside the project tree, compare actual code paths, and translate gaps into prioritized actions.

## Output rule
Keep observations separate from inferences, and always record gaps.
