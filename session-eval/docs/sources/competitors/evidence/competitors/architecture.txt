The evidence separates (1) full self-hostable platforms (Opik, LangWatch core, Langfuse, Evidently, Helicone, Phoenix), (2) local evaluator/SDK layers (Promptfoo, Ragas, TruLens, Weave, OpenLLMetry), and (3) agent-facing connectors (MCP, CLI, coding-agent session integrations). A first-party Styrir skill should normalize provider events into a local session/trace schema, run evaluator adapters, and emit portable HTML plus trend data while keeping licensing and hosted-service boundaries explicit. Phoenix's ELv2 hosted-service restriction rules out vendoring it as a hosted product.
