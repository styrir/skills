Phoenix provides a live React/Vite observability SPA backed by GraphQL, with rich project, trace/session, dataset/experiment, evaluator, and dashboard views. Its source contains no data-bearing static HTML trend-report exporter; only span/trace JSON/OTLP downloads were found. Claude and Codex integrations expose the Phoenix MCP plus a separately installable CLI/skills contract, while Harbor evaluates a multi-step headless regression-triage workflow.
